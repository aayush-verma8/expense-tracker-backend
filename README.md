# Expense Tracker (Full Stack)

A full-stack expense tracking application built using **Spring Boot, JWT Authentication, MySQL, and React**.

## Features
- User registration
- User login with JWT authentication
- Secure API endpoints
- Add expenses
- View expenses
- Edit expenses
- Delete expenses
- Expense filtering
- Total expense calculation

## Tech Stack

Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- JPA / Hibernate
- MySQL

Frontend
- React
- Axios
- React Router

## API Endpoints

Authentication

POST /api/auth/register  
POST /api/auth/login  

Expenses

GET /api/expenses  
POST /api/expenses  
PUT /api/expenses/{id}  
DELETE /api/expenses/{id}
